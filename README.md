# My Python Toolkit

## Project Description

My Python Toolkit is a menu-driven Python program that contains three useful tools: a simple calculator, a to-do list, and a number checker.

The calculator performs basic arithmetic operations. The to-do list allows users to add, view, and remove tasks. The number checker identifies whether a number is positive, negative, or zero.

## How to Run

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the command `python toolkit.py`.
5. Choose a tool from the menu and follow the instructions.

## Concepts Practiced

* Variables and data types
* User input and output
* If, elif, and else statements
* While and for loops
* Lists and list methods
* Functions
* F-strings
* Error handling with try and except

## Reflection

The hardest part of this project was connecting all three tools to one menu that keeps running until the user chooses to quit. The bug that took the longest to fix was handling invalid user input without crashing the program. I learned how to use functions to organize code and make it easier to read. I also learned how lists can store tasks and change as users add or remove items. Testing each menu option helped me understand how loops and conditionals work together. I am proud that the program can handle invalid choices and display friendly messages. If I had one more week, I would add a number-guessing game and save the to-do list so tasks remain available after the program closes.
